# EVIoT — Electric Vehicle IoT Predictive Maintenance Frontend

This is the frontend application for the EVIoT predictive maintenance platform.

## Tech Stack
- React 18
- Vite
- TypeScript
- Tailwind CSS v3
- React Router v6
- Lucide React (Icons)
- Recharts (Charts)
- Axios (HTTP client)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Environment Configuration:
   Copy `.env.example` to `.env` and adjust settings. By default, it uses the mock API for demonstration.

3. Start development server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```
